文档翻译工具 · 自定义术语表
================================

用途：把反复译错的词、单位术语、产品名固定成指定译法。改这个文件不用改程序，
在线模式和保密模式都会读它，保存后重新翻译即可生效。

写法：每行一条，中间用等号分开，等号左边是原文，右边是想得到的中文。
      # 开头的行是说明，不生效。大小写、首尾的标点和多余空格都不用管。
      原文过长（超过 40 个字符）的条目会被忽略，避免误伤正文。

生效范围（重要）：这里写的术语在两种情况下都会生效——
      1. 整段就是一条标题或术语（例如段落只有 "Healthcare"）；
      2. 正文长句里出现的同一个词（例如 "Net profit rose…" 里的 net profit）。
      第 2 种是「术语锁定」：翻译前先把术语换成模型碰不到的占位符，译完再换回
      你指定的中文。所以无论长句被拆成几段、模型怎么发挥，同一个术语在全篇
      只有一种译法，不会出现「净利润 / 净收益 / 净利」混着来的情况。

下面这些是程序已经内置的，写成注释供参考，需要改译法时把行首的 # 去掉即可：
# Healthcare = 医疗保健
# Impact = 影响
# Appendix = 附录
# 目次 = 目录
# Оглавление = 目录

建议放这里的内容：
1. 单位/行业术语的固定叫法，例如：
# Deep Learning = 深度学习
# Informed Consent = 知情同意
2. 不希望被翻译的专有名词、系统名、文号，译成和原文一样即可，例如：
# Project Atlas = Project Atlas
3. 离线模型反复译错的人名、地名、产品名，例如：
# AI in Education = 教育人工智能

注意：
1. 拉丁文术语按「整词」匹配（note 不会命中 denote，AI 不会命中 said），中文和
   俄文术语按子串匹配，不需要词边界。
2. 长术语优先："net profit" 和 "profit" 同时存在时，先锁 "net profit"。
3. 最多生效 80 条，按原文长度从长到短排。
4. 不想被翻译的专有名词，等号左右写一样即可（Project Atlas = Project Atlas）。
